LUDHIANA TOMATO—

What the code enforces rather than trusts
01

No unsourced agronomy

Every efficacy figure and degree-day base lives in a versioned file with a citation and a validity range. A missing parameter raises; there is no default-returning lookup anywhere in the store.

02

No constraint met by relaxing the model

If the modelled application count exceeds your cap, the plan says so. A coefficient asked to speak outside the envelope it was measured in raises rather than extrapolating.

03

Solving is free, committing is gated

Re-solve as often as you like. Committing a plan of record funnels through one approval check — one choke point, because a second code path is how a gate eventually gets bypassed.

04

Ingested text is data, never instruction

Free text from uploaded files is fenced and labelled before it reaches a prompt, and the fence token is escaped so a hostile note cannot close its own quoting.

The number this demo will not show you

How many sprays an intercropped layout saves. There is no pressure model yet, and every interaction coefficient on file is provisional and unsourced — so the honest answer is that we cannot yet say, and a figure here would be invented.
